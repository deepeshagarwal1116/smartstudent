# Smart Student – Assignment Management Platform

A full-stack web application that helps students and teachers manage assignments efficiently with role-based access.

## Features
- Role-based authentication (Student / Teacher)
- Assignment creation, submission, and tracking
- REST API backend with Node.js & Express
- Responsive UI built with React.js

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express
- **Database:** MongoDB
